# PImaster EDT — Preview

PImaster EDT is an unofficial Windows tool for planning EVE Online planetary industry layouts.

## Download

**[Download PImaster EDT 0.8.92-pre for Windows x64](https://github.com/Abysilure/PIMaster_EDT/releases/download/v0.8.92-pre/PImasterEdt-0.8.92-pre-win-x64.zip)**

Download the ZIP, extract it completely, and open `PImasterEdt.exe`. SHA-256: `4f0ba3085f4fbb74ab7c2fa7b7a945de18ed9784cc2992420d30b3132fb74f36`.

The interface starts in English and can be switched to Chinese. Microsoft Edge WebView2 Runtime is required. This preview is signed with a self-signed test certificate that Windows does not trust by default; a security warning or block may occur.
